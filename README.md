# Digital Tasbeeh Counter

Digital Tasbeeh Counter is a beginner-level Flutter project developed using Dart and Object-Oriented Programming concepts.

The app allows users to select a Dhikr, increase the count, reset the counter, and check when the target is completed.

## Features

- SubhanAllah counter with target 33
- Alhamdulillah counter with target 33
- Allahu Akbar counter with target 34
- Count button
- Reset button
- Target completion message
- Simple Flutter GUI

## OOP Concepts Used

- Class
- Encapsulation
- Private properties
- Getters
- Default constructor
- Named constructors
- Methods
- Boolean getter
- Mixin
- `with` keyword
